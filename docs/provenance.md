# Provenance

This public package was prepared on October 16, 2026 from lessons learned in the owner's retired local provider-routing experiment. The historical Space Bunny Alpha name identifies that case study; the integration has not been reactivated for publication.

The implementation is an original extraction/rewrite of selected compatibility methods, extended with explicit provider profiles, a foreground two-protocol client, and opt-in probes. Regression fixtures use synthetic conversations, IDs, tools, credentials, and data sentinels. Automated transport tests use temporary loopback servers, not a real provider.

The package excludes the operational proxy, model aliases/catalogs, startup watchers, legacy launchers and credential loaders, encrypted stores, personal configuration, session archives, memories, raw diagnostics, private endpoints, project content, and third-party application source. No legacy Git history was imported.

`PUBLICATION_FILES.json` lists exact intended files. The audit examines the current tree except Git metadata; private configs belong outside it. Publication also reviews the staged diff and commit identity. This is a scoped package review, not a forensic certification of the computer.

The case study distinguishes observed logs, source mechanisms, plausible risks, and unresolved correlations. Aggregate counts are not raw logs or unique incident totals. The community roadmap records intended products separately from what is actually delivered here.

MIT covers this repository's original code and documentation. Product names and linked protocol documentation remain their owners' property. References imply no vendor endorsement. No provider compatibility, store submission, or official bug acceptance follows merely from publication.
